Topic : JAVA ARRAYS:
-----------------------------

Java array is an object which contains elements of a similar data type.  

  Syntax:
         <datatype> varaible_name[size];
 -> array size- 0 to n-1 

   array initialization :(creating the array)
-------------------------------------------
    <datatype> <var>[size]=new <datatype>[size];

   Example :
            int a[]=new a[2];

      //a[2] i.e a[0]  a[1] 
                 a[0]=10; a[1]=20;                

________________________________________________
Types of arrays:
------------------
1)1-D (one-dimensional)- its define only one indices
                      ex: int a[]=new int a[5];

2) 2-d(Two-dimensional)-its define only two indices
                 ex: int a[][]=new int a[2][2];

Types of array:
-----------------

1) Single Dimension arrays : single dimension array to defines one indices .
----------------------------
   Syntax: 
          datatype <var>=new <datatype>[size];

  Example:
              int a=new a[5];
 

2) Two-dimensional arrays: Two-dimensional array to define two indices .
-------------------------
 Syntax: 
          datatype <var>=new <datatype>[size][size];

   Example:
              1) int a=new a[5][5];

              2) int[][] matrix = {{10, 20, 30},{40, 50, 60},{70, 80, 90} };
              3) int a[][]=new int[2][2];

import java.util.Scanner;

class MatrixAdd
{
        public static void main(String args[]) 
       {
        Scanner obj = new Scanner(System.in);

        System.out.println("Enter the row size:");
        int r = obj.nextInt();
        System.out.println("Enter the column size:");
        int c = obj.nextInt();

        int a[][] = new int[r][c];
        int b[][] = new int[r][c];
        int sum[][] = new int[r][c];

        System.out.println("Enter the elements of first matrix:");
         for (int i = 0; i < r; i++) 
         {
            for (int j = 0; j < c; j++) 
           {
                a[i][j] = obj.nextInt();
            }
        }

        System.out.println("Enter the elements of second matrix:");
        for (int i = 0; i < r; i++) 
         {
            for (int j = 0; j < c; j++) 
            {
                b[i][j] = obj.nextInt();
            }
        }

           // logic of sum matrix 
         for (int i = 0; i < r; i++) 
         {
            for (int j = 0; j < c; j++) 
            {
                sum[i][j] = a[i][j] + b[i][j];
            }
        }

  
          System.out.println("The sum of two matrices is:");
            for (int i = 0; i < r; i++) 
           {
            for (int j = 0; j < c; j++)

import java.util.Scanner;

class MatrixTranspose 
{
        public static void main(String args[])
       {
        Scanner obj = new Scanner(System.in);

        System.out.println("Enter the row size:");
        int r = obj.nextInt();
        System.out.println("Enter the column size:");
        int c = obj.nextInt();

        int a[][] = new int[r][c];

        System.out.println("Enter the elements of the matrix:");
        for (int i = 0; i < r; i++) 
        {
            for (int j = 0; j < c; j++) 
            {
                a[i][j] = obj.nextInt();
            }
        }

        System.out.println("\nTo Display the Matrix:");
        for (int i = 0; i < r; i++) 
        {
            for (int j = 0; j < c; j++) 
            {
                System.out.print(a[i][j] + " ");
            }
               System.out.println();
        }

        // Find transpose
        int trans[][] = new int[c][r];  // int[2][2]
        for (int i = 0; i < r; i++) 
         {
            for (int j = 0; j < c; j++) 
            {
                trans[j][i] = a[i][j];  // trans[0][0]=a[0][0]
            }
        }

      
        System.out.println("\nTranspose of the Matrix:");
        for (int i = 0; i < c; i++) 
        {
            for (int j = 0; j < r; j++) 
           {
                System.out.print(trans[i][j] + " ");
            }
            System.out.println();
        }

       
    }
}
